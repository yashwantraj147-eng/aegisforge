# Security Policy

## Permitted Environment and Scope
AegisForge is designed solely for local defensive engineering, education, and purple-team range exercises.
- All network and scanning operations are restricted to private RFC 1918 subnets and loopback addresses.
- Active probes against external WAN targets are strictly blocked by the internal SafetyGuard.

## Reporting Vulnerabilities
If you identify a security issue within this software:
1. Please submit an advisory draft to `security@aegisforge.internal`.
2. Do not open public GitHub issues for unpatched vulnerabilities.
3. Include relevant version details and reproduction steps.
